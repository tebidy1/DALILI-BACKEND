# دليلي — الخادم (DALILI Backend)

خادم واجهة برمجة التطبيقات (API) لأداة **دليلي**: يخزّن الأدلة العربية، والمشاركة بالرابط بلا حساب، والبحث على مستوى الخطوة، ونسخ الصوت (STT). صفر اعتماد خارجي في وقت التشغيل عدا تحويل الصوت.

> جزء الخادم من مشروع دليلي. الواجهة والامتداد في مستودع منفصل: `DALILI-FRONTEND`.

## البنية

مستودع pnpm (workspace) يحوي:

| الحزمة | الوصف |
|---|---|
| `apps/api` | خادم Fastify + Drizzle + better-sqlite3 |
| `packages/core` | منطق نقي بلا اعتمادات (مشترك) |
| `packages/shared` | عقود zod المشتركة |

## التشغيل

```bash
pnpm install                      # تثبيت الاعتمادات
cp apps/api/.env.example apps/api/.env   # ثم عبّئ القيم الحقيقية
pnpm dev                          # الخادم على المنفذ 8787
pnpm test                         # كل الاختبارات
pnpm typecheck                    # فحص الأنواع
```

## متغيّرات البيئة (`apps/api/.env`)

| المتغيّر | الوصف |
|---|---|
| `COOKIE_SECRET` | سرّ توقيع الكوكيز (٣٢ حرفاً على الأقل) |
| `DATA_DIR` | مجلّد قاعدة البيانات والملفّات (`data`) |
| `PUBLIC_BASE` | العنوان العام للخادم |
| `GROQ_API_KEY` | مفتاح Groq لتحويل الصوت إلى نص |

انظر `apps/api/.env.example`.
